# پاساژیار — دستیار هوشمند خرید حضوری

دستیار خرید حضوری از فروشگاه‌ها و پاساژهای تهران، روی دیتاست ترب (۶٬۴۷۶ فروشگاه، ۲۲۵٬۹۰۳ کالا، ۳۳۱٬۵۰۶ آفر).
فارسی، راست‌به‌چپ و موبایل‌محور.

## چهار گام
1. **چی می‌خوای؟** نیاز به زبان آزاد («هندزفری برای دویدن زیر ۳ میلیون»). LLM نیاز را به کلیدواژه، بودجه، کاربرد و ویژگی‌های لازم تبدیل می‌کند، نکته خرید می‌دهد، سؤال تکمیلی می‌پرسد و از بین نتایج ۳ مدل را با دلیل پیشنهاد می‌کند. بدون LLM هم با قواعد کار می‌کند.
2. **کدام فروشگاه‌ها دارند؟** فاصله و زمان رسیدن از موقعیت کاربر (GPS یا محله)، نقشه با برچسب قیمت، و دو سطح جدا: «آفر ثبت‌شده» و «فقط در این دسته فعالیت دارد — موجودی نامشخص».
3. **مقایسه فروشگاه‌ها:** امتیاز ترکیبی (قیمت، فاصله، باز بودن، تازگی قیمت، اقساط، گارانتی) همراه دلیل‌ها و هشدارها، جدول مقایسه کنار‌به‌کنار، و پیشنهاد «چند فروشنده در یک پاساژ».
4. **دستیار از فروشگاه می‌پرسد:** پیام استعلام (موجودی، قیمت نهایی، اقساط، گارانتی، رنگ، ساعت، کنار گذاشتن تا زمان مراجعه) را می‌سازد و پاسخ‌ها را با وضعیت «ارسال شد ← دیده شد ← پاسخ داد» پیگیری می‌کند. بهترین گزینه تأییدشده و برنامه مراجعه چندتوقفی را با لینک گوگل‌مپ می‌دهد. اگر فروشگاهی کالا را نداشت یا جواب نداد، فروشگاه‌های دیگر و کالای جایگزین پیشنهاد می‌کند.

### فیچرهای دیگر
- **فیلتر اعتبار قسطی** (ترب‌پی، اسنپ‌پی، دیجی‌پی، تارا) با برچسب نوع اطلاعات: «پذیرنده حضوری (اعلام فروشنده)» یا «نامشخص».
- **«چطور پیدایش کنم؟»** آدرس به پاساژ، طبقه و واحد/پلاک تجزیه می‌شود. لینک مسیر در گوگل‌مپ، نشان و بلد هست، و اگر خود مغازه پیدا نشد، جستجوی نام پاساژ در گوگل‌مپ و فهرست همسایه‌های همان پاساژ.
- **شفافیت:** قیمت ثبت‌شده، زمان به‌روزرسانی قیمت و موجودی تأییدشده جدا نمایش داده می‌شوند. قیمت‌های پرت یا مشکوک (۳٬۹۶۰ آفر) و بدون قیمت (۱۵٬۰۸۳ آفر) برچسب می‌خورند و در رتبه‌بندی حساب نمی‌شوند. هر اطلاعات ثبت‌نشده صریحاً «نامشخص» نشان داده می‌شود.
- **ساعت کاری:** وضعیت‌های «الان باز است تا …»، «به‌زودی می‌بندد» و «بسته — فردا از …» به وقت تهران.
- **مقایسه کالاها:** حداکثر ۴ کالا، با پررنگ شدن ردیف مشخصاتی که با هم فرق دارند.
- **پنل فروشنده (دمو):** چون شماره‌های دیتاست جعلی‌اند، فروشنده از `/seller` جواب می‌دهد. برای فروشگاه‌هایی که پنلشان باز نیست، پاسخ شبیه‌سازی می‌شود و برچسب «شبیه‌سازی‌شده» می‌خورد.

## معماری
- **Backend:** FastAPI و SQLite با FTS5 (نرمال‌سازی فارسی ی/ک، ارقام و نیم‌فاصله). کد در `backend/app`:
  `catalog` (جستجو، رتبه‌بندی، جایگزین‌ها)، `geo` (فاصله، ساعت کاری، لینک نقشه)، `intent` (LLM و fallback قاعده‌محور)، `inquiries` (استعلام، شبیه‌سازی، پیگیری، برنامه مسیر).
- **LLM:** BoxAPI با مدل `gpt-6-luna`. پاسخ‌ها کش می‌شوند و سقف هزینه سخت دارد (`LLM_BUDGET_USD`، پیش‌فرض ۰٫۵ دلار). هر فراخوانی حدود ۰٫۰۰۰۲ دلار است.
- **Frontend:** React، Vite و Tailwind v4، فونت وزیرمتن به‌صورت self-host، Leaflet و OSM.
- **داده:** `scripts/build_db.py` از CSV یا `data/seed/*.csv.gz` دیتابیس `app.db` را حدود ۴۰ ثانیه‌ای می‌سازد.

## اجرا (محلی)
```bash
python -I scripts/build_db.py data/raw data/app.db
cd frontend && npm i && npm run build && cd ..
.venv/Scripts/python -m uvicorn app.main:app --app-dir backend --port 8000
```

## کیفیت کد
```bash
cd backend && ../.venv/Scripts/python -m pytest -q      # ۲۳ تست: بودجه، ساعت کاری، رتبه‌بندی، چرخه کامل استعلام
../.venv/Scripts/python -m ruff check app tests ../scripts
cd ../frontend && npx tsc -b && npx oxlint src
```
- بک‌اند: لایه دیتابیس جدا (`db.py`؛ اتصال فقط‌خواندنی جدا برای هر thread)، اعتبارسنجی ورودی با Pydantic (`schemas.py`)، تبدیل ارقام به فارسی فقط در لایه پاسخ API (`i18n.py`)، وزن‌های رتبه‌بندی به‌صورت ثابت‌های نام‌دار، و fallback قاعده‌محور برای هر فراخوانی LLM.
- فرانت‌اند: هر صفحه جدا و lazy بارگذاری می‌شود (نقشه Leaflet فقط وقتی لازم است)، ErrorBoundary، صفحه ۴۰۴، اعلان (toast)، انیمیشن‌های ورود صفحه و لیست و شیت و تب و نشان‌ها با احترام به `prefers-reduced-motion`.

## دیپلوی روی لیارا
```bash
npm i -g @liara/cli
liara login
liara app create pasajyar --platform docker   # یا از پنل
liara env set LLM_API_KEY=<کلید BoxAPI> LLM_BUDGET_USD=0.5 --app pasajyar
liara deploy --app pasajyar --port 8000
```
- ساخت دیتابیس در Docker build انجام می‌شود، پس فقط حدود ۶۰ مگابایت داده آپلود می‌شود. حجم image حدود ۷۰۰ مگابایت است.
- اختیاری: برای ماندگار شدن استعلام‌ها و شمارنده هزینه LLM، یک دیسک بسازید و به `/app/state` وصل کنید (`liara disk create`).
