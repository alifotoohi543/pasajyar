# چالش: دستیار هوشمند خرید حضوری (ترب / Starcoach)

دستیار هوشمند خرید حضوری از فروشگاه‌ها، پاساژها و مراکز خرید تهران.
۴ گام دستیار در ویدئو توضیح داده شده (← از توضیحات کاربر تکمیل شود).

## الزامات کلیدی
- قیمت ثبت‌شده ≠ زمان تغییر قیمت ≠ موجودی تأییدشده — قاطی نشوند.
- اطلاعات نامشخص صریح نمایش داده شود.
- دسته فعالیت فروشگاه ≠ موجود بودن محصول.
- کاربر بتواند محدوده، بودجه و شرایط خرید را راحت عوض کند.
- نشان بدهیم چرا پیشنهاد شده و قدم بعدی چیست.
- ویدئوی دمو ~۵ دقیقه (الزامی).
