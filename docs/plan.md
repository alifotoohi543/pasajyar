# نقشه محصول — «دستیار خرید حضوری»

## ۴ گام اصلی (از ویدئو) → فیچر
| گام | نیاز | فیچر | معیار داوری |
|---|---|---|---|
| ۱. چی می‌خواد؟ | کاربر مدل مناسب را نمی‌داند + مقایسه کلی قیمت | ورودی آزاد («هندزفری برای دویدن زیر ۲ میلیون») → LLM نیاز را به دسته/بودجه/ویژگی تبدیل می‌کند → کارت محصولات با بازه قیمت (کمینه/میانه/بیشینه بین فروشنده‌ها، تعداد فروشنده، تازگی قیمت) + چیپ‌های فیلتر (بودجه، برند، مشخصات کلیدی) + مقایسه کنار‌به‌کنار مشخصات + «چرا این پیشنهاد شد» | محصول، هوشمندی |
| ۲. کدوم فروشگاه‌ها دارن؟ | با توجه به لوکیشن کاربر | لوکیشن (GPS / انتخاب روی نقشه / محله) → لیست + نقشه فروشگاه‌ها با فاصله؛ دو سطح: «آفر ثبت‌شده» و «فقط در این دسته فعالیت دارد — موجودی نامعلوم» | محصول، دیتاست |
| ۳. مقایسه فروشگاه‌ها | قیمت، ساعت کاری، … | جدول مقایسه: قیمت، تازگی قیمت، فاصله، «الان باز است / تا ۱۹ باز»، قسطی، گارانتی، ارسال فوری؛ امتیاز ترکیبی با دلیل («ارزان‌ترین، ۸۰۰ متر، تا ۱۹ باز») | UX، هوشمندی |
| ۴. سؤال از فروشگاه + اطلاع به فروشگاه | ایجنت با فروشگاه ارتباط بگیرد | ایجنت سؤال می‌سازد (موجودی، قیمت نهایی، رنگ، قسطی، ساعت) و برای چند فروشگاه می‌فرستد؛ **پنل فروشنده** (شبیه‌سازی، چون شماره‌ها جعلی‌اند) جواب می‌دهد؛ صفحه «پیگیری» با وضعیت هر درخواست؛ رزرو/کنار گذاشتن («ساعت ۱۷ میام»)؛ عدم پاسخ یا ناموجود → پیشنهاد خودکار فروشگاه/محصول جایگزین | هوشمندی، محصول |

## فیچرهای اضافه (اولویت‌دار)
1. **فیلتر اعتبار قسطی** (خیلی مهم): فقط فروشگاه‌هایی با ترب‌پی/اسنپ‌پی/تارا/دیجی‌پی؛ برچسب نوع اطلاعات (حضوری اعلام‌شده / نامشخص).
2. **مسیریابی داخل پاساژ**: پارس آدرس → پاساژ/مجتمع، طبقه، واحد/پلاک → کارت «چطور پیدایش کنم» + لینک گوگل‌مپ/نشان/بلد با مختصات و نام پاساژ.
3. **شفافیت**: قیمت ثبت‌شده ≠ تازگی قیمت ≠ موجودی تأییدشده؛ نشان «تأیید فروشنده X دقیقه پیش»؛ «نامشخص» صریح؛ قیمت‌های پرت پرچم می‌خورند.
4. **برنامه پاساژگردی**: لیست خرید چندقلمی → کمترین تعداد توقف/مسیر، فروشگاه‌های هم‌پاساژ.
5. شرایط مراجعه: «الان باز است؟»، تعطیلی جمعه، زمان رسیدن.

## پاکسازی دیتا
- قیمت null → «قیمت ثبت نشده — بپرسید»؛ قیمت پرت (نسبت به میانه همان محصول یا ≤1000 تومان یا >1e11) → پرچم و خارج از رتبه‌بندی.
- تازگی: < ۷ روز تازه، < ۳۰ روز نسبتاً تازه، بیشتر قدیمی.
- نرمال‌سازی فارسی برای جستجو (ي/ك، ارقام، نیم‌فاصله).

## استک (پیش‌فرض)
FastAPI + SQLite (FTS5) | React + Vite + Tailwind، RTL، فونت وزیرمتن، Leaflet | LLM از BoxAPI فقط برای فهم نیاز، توضیح و متن پیام (با fallback قاعده‌محور) | یک ایمیج Docker برای دیپلوی.
